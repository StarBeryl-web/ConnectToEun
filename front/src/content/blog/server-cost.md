# 고객님께 드리는 핵심 안내(보안/운영 관점)

- 개인정보 보안은 **“누가 지속적으로 관리하느냐”가 핵심**입니다.
- **관리자가 없는 환경이라면**, 로그인/DB/파일은 **관리형 서비스(Supabase 등)**로 두는 게 더 안전하고 사고 대응도 빠릅니다.
- **직접 운영해야 하는 서버(EC2/전통 호스팅)**는 월 운영관리 계약 없이 방치되면 리스크가 커집니다.

## A / B / C 패키지 비용표 (변동)

| 패키지 | 포함 기능(고객 관점) | 정확한 스택/플랜 | 월 고정비(최소) | 변동비가 붙는 경우 | 운영난이도 |
| --- | --- | --- | --- | --- | --- |
| **A. 프론트만** | 소개/랜딩/포트폴리오/문의 페이지 | **Vercel Pro**: $20 / seat / month | **$20부터** | 트래픽/빌드/기능 사용량이 커져 포함량 초과 시 | 🔥 |
| **B. 프론트 + 백(Supabase)** | 로그인, 데이터 저장, 파일 업로드, 간단 관리자(권한) | **Supabase Pro**: $25 / project / month + **Vercel Pro**: $20/seat/mo | **$45부터** | 이미지 저장/다운로드(대역폭), DB 용량/성능, 동시접속/요청량 증가 | 🔥🔥 |
| **C. 프론트 + 백 자체 개발(AWS EC2)** | 복잡한 로직/확장/회사 정책(통제) | **AWS EC2 t3.small**: $0.0208/hr ≈ $15/mo + **AWS S3**(파일) + (선택) DB: **RDS** 또는 **Supabase** + **Vercel Pro** $20/seat/mo | **대략 $35+ (EC2+Vercel) + S3/DB** | **S3 데이터 전송(다운로드)**, 서버 스펙 업(트래픽↑), DB를 RDS로 두면 고정비 상승 | 🔥🔥🔥🔥 |

> 별도 안내: 도메인(예: yourbrand.com)과 HTTPS(보안 접속)는 Vercel에서 일반적으로 자동 적용이 가능하며, 호스팅/배포 구조는 서비스 요구사항에 맞춰 위 패키지 중 선택합니다.

## 운영관리(월 정액) 권장 문구 – C 패키지용

**C 패키지(직접 서버 운영)는 보안 업데이트/백업/모니터링/장애 대응이 필수**이므로, 아래 중 하나를 권장합니다.

- **(권장) 월 운영관리 정액 계약 포함**: 보안 패치, 장애 1차 대응, 백업 점검, 기본 모니터링
- **(대안) 고객사 내부 운영 담당자 지정**: 내부 담당자가 없으면 유지 리스크가 커짐

## 고객 계정 안내(인수인계/소유권 안전)

- 서비스 계정(Supabase/Vercel/AWS)은 **고객사 명의로 생성**하고
- 개발사는 **멤버 초대 방식으로 권한을 받아 작업**하는 것을 기본 원칙으로 합니다.
  (아이디/비밀번호 공유 방식은 지양)
